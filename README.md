# 🦸 AERON — The Guardian Who Listens

> **No voice should ever go unheard.**

AERON is an interactive superhero help portal created for the **TECHASCENT – MACHINE TEST**.

Aeron is a futuristic guardian whose special ability, **EchoSense**, allows him to understand the emotion and urgency behind people's words.

## 💬 How It Works

The visitor begins a conversation with Aeron.

The chatbot naturally collects:

1. Name
2. Age
3. Location
4. Email address
5. Grievance or request

After the visitor submits their request, the information is automatically sent through EmailJS.
